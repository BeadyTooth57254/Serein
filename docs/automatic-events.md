# 自动 Event

自动整理采用归线 → 切分与图片转录 → Event 写作三阶段，不再单独调用原话证据整理。Event 直接保存到记忆库，不进入 Bridge 信箱；Scene 仍由聊天中的 agent 主动写。原话编号、来源绑定与哈希、图片转录和 Writer 自检继续保留。

升级时忽略旧的 `event_evidence` 模型选择；旧页面提交该字段仍可保存其他配置。停在该阶段的任务继续时直接进入 Writer，已完成的归线、切分及历史回执保留；历史 Event 的旧证据整理结果不删除。

公开版聊天代理在收到成功回复后，把当前用户原话和完整助手正文写入消息库，使用已有的原话编号、搜索与流水线待处理入口。流式响应必须正常结束；工具调用阶段只保存用户原话，最终正文回来后补齐助手消息。系统提示、推理、工具返回和注入材料不作为原话归档，图片保留材料引用。关闭自动摘要或记忆召回不影响原话保存。

客户端应传稳定的 `serein.window_id` 或 `X-Serein-Window-Id`。重试和工具续轮按窗口及原始对话去重；提供消息 `id` / `message_id` 时，裁剪历史后仍可识别同一消息。没有消息 ID 的客户端若同时改变历史，无法可靠识别其是否为旧请求；不同窗口也不应共用默认的 `main`。时间记录为代理接收/回复完成时间，不伪造历史消息时间；不会自动补录请求携带的旧聊天。入库失败或内容被拒绝会记在请求诊断的 `raw_archive` 中，不丢弃已经生成的回复。

自动摘要开关在设置 → 功能中，保存后生效。点击“自动摘要配置”跳转到配置页，选择执行方式和参数。三个阶段分别为归线、切分与转录、Event 写作，也在“配置”页选择模型。“模型”页管理上游地址、密钥和模型目录；打开时直接显示已配置上游，各上游里的模型和编辑项默认收起。

- API：三阶段都需要已配置的模型，远程上游需要密钥。切分与 Writer 使用图片内容块及 JSON 输出，需选支持这些能力的模型。
- Agent：由用户已安装、已认证的执行器连接 `scripts/event_agent_mcp.py`，领取任务并提交结果。图片通过 MCP image content 返回。阶段模型字段作为执行提示，由执行器按自身支持的模型选择执行；网页不会安装或启动私有 CLI，也不会继承其他机器的登录状态。
- 升级前未设置执行方式的实例保留按阶段选择 API/Agent 的兼容行为，直到用户明确切换。旧客户端保存其他设置不会清掉 Event 配置。新客户端保存时校验设置版本，冲突后需刷新核对。

一轮执行开始时冻结三阶段模型、身份和超时。运行中修改设置不影响该轮；下一轮继续任务时读取新配置，已完成步骤保留。模型凭据只在服务端内存中使用，不放进 Agent 任务或浏览器响应。切换不重跑已完成 Event、不修改结算游标。

## 材料和保护

完整问答单元必须保持同一主 Track，Curator 选择完整单元。原文覆盖、Router 声明的 bridge 和已有 Event 保护都由程序校验。受保护提案会让共享稳定单元的相连提案整条、传递性暂缓；独立提案继续处理。原本非法的重复归属不会因保护触发而通过校验。

extend/merge 的输入保留所有所选前版正文及其绑定原文，与新原文一起提供。前版正文用于检查遗漏，不能代替原始证据。新的规则不会自动修复历史正文，也不会解除旧条保护。修订来源和保护来源的进一步区分不包含在本次改动中。

第一次切分前，按本批阅读原文的来源、会话、消息编号及内容哈希查已有 Scene（包括已归档、排除已删除或解绑的内容）。同一 Scene 只提供一份完整正文，附命中的本地原文编号；Curator 与 Writer 使用同一份快照。查询失败或超过完整读取预算会停止，不按空结果处理，也不截断后继续。

模型对照原文与 Scene 实际内容：已经完整记录且没有新展开的单元可以跳过，新的讨论仍保留；同一不可拆单元混有新旧内容时保留完整归属，由 Writer 省去已记部分。命中绑定不等于整条消息都记过，Scene 不成为新原文、不扩大归属，也不解除旧 Event 的保护。

写入前在同一数据库事务中复查 Scene 正文、版本、状态和匹配绑定；不一致时回滚 Event 及原话处理状态，包括只有跳过项的批次。下次运行重新读取 Scene、重新切分，不复用失效的模型结果。Agent 等待期间也执行这项检查。Scene 的核对收据保存在 Event 详情的 `existing_scene_receipts`，此功能不修改 Scene 本身。

Curator 逐图读取可用原图，转录图片中可见的标题、正文、评论；不可辨认处明确标记。模型只能提供图片序号、文字与 unreadable，程序绑定真实消息 ID、图序、SHA-256 和阅读角色。每图必须恰有一份转录，重复、遗漏或自报出处均被拒绝。

Writer 同时读取转录及相同字节的原图，修复重试保留这些材料。context_only 图片与文字不扩大归属。Curator 和 Writer 分别至多请求一次有界补读：程序只读指定 Track、允许会话和给定边界前的最多六个完整单元。Writer 补读带来的图片另外转录，不重新决定 Event 边界。转录收据保存在 `pipeline_event_details.details_json.curator_image_transcriptions`，不创建独立结果摘要表。

公开版直接使用导入附件里的图片数据或公开 HTTP(S) 原图地址，不扫描宿主会话目录。远程图像不跟随重定向、拒绝内网地址；单图上限 10 MB，每批最多 24 张、40 MB，超出时要求减小批次，不静默截断。

已完成任务中的临时图像副本在完成七天后、下次流水线维护时清除；未完成任务用于恢复的副本仍保留。原话档案中的附件属于原始存档，不随任务缓存清理；已保存的转录文字也保留。这里没有独立的上传文件池，不把其他宿主的文件清理规则当作已实现功能。

## 人工核对

自动摘要可能切分不当、遗漏细节、判断错重点，或混淆引用出处、人物归属和原话的确定程度；图片识别也可能出错。重要内容请结合原始对话核对并按需修订。部分材料会因上下文未结束、已有内容受保护或模型服务失败而暂未生成。

流水线显示失败记录、跳过及保护暂缓情况。Event 列表支持多选、全选当前筛选、归档、取消归档、不自动浮现和确认删除。只按服务端回执更新；失败项保留选择。取消归档不恢复已关闭的自动浮现资格。删除确认包含数量及不可撤销含义，并按回执处理整个修订家族；原话档案保留。

模型自报 self_review 不能证明语义准确率。本轮保留结构、长度、证据与来源校验，去掉按特定措辞或出现次数拒稿的规则；没有准确率数字或完全保真的承诺。
