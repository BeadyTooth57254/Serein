# 叙事卷：选材、书写与修订

## 按主题找材料

“找材料”读取设置 → 配置中的 **叙事卷找材料** 模型，没有配置时给出提示，不调用隐含上游。支持当前公开版的 OpenAI Chat Completions 兼容协议及 Anthropic Messages，密钥只在后端使用。向量检索使用已准备的当前 Embedding 配置；不可用时提示并退回主题词检索，不自动准备索引。

每次先扩展最多 8 个检索词，融合词面与向量候选后，最多向模型发送 16 条材料摘录，摘录总计不超过 8,000 字符。输出 token 上限分别为 1,000 / 1,800；GPT 模型使用低推理预算。最终最多选 10 条，标题最多 16 字符。未解锁、不可读的日记不进入模型材料。

找材料不创建卷或修改绑定。保存前核对每条来源的当前内容凭据；漂移则拒绝保存，重复请求按请求 ID 幂等处理。“保存叙事线”创建空白 collecting 卷；明确点击“书写”会调用公开版 Writer 并保存首篇正文。已有正文的更新／重写仍先预览再确认保存；主题独立于短书名传给 Writer，保留配置姓名和原文图片读取规则。

修订扫描开始前，撤出 archived/superseded Event 和 archived Scene 的绑定，保留原始材料、已写正文、发布日期和历史。绑定修订会递增版本，但不单独制造新的修订提醒；已有提醒的处理状态保留。缺失或删除的材料仍交由现有审阅流程处理。旧 Arc key 缺失不会阻断这一流程。

## 修订箱

每天凌晨四点后，程序检查已有叙事卷所关联的 Event、Scene、日记和窗影。若其中有效材料的创建、更新或自动关联时间晚于卷的发布时间，就放入一条待判断的修订提醒；不调用模型，不写正文，也不会自动寻找新主题。没有晚于发布时间的变化就不提醒。已升为 Scene 的 Event 不再作为修订材料。

修订箱只显示已有卷的更新提醒。下一次扫描会把旧版模型生成、仍在待处理的“可能成卷”候选标为退出队列，保留历史内容；不会继续生成此类候选。想开启新主题，请在叙事卷页输入主题手动找材料。手动找材料仍使用设置页的“叙事卷找材料”模型，审阅后才保存叙事线或书写。
