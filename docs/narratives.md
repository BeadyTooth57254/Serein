# 叙事卷：选材、书写与修订

## 按主题找材料

“找材料”读取设置 → 配置中的 **Narrative Scout**，没有配置时给出提示，不调用隐含上游。支持当前公开版的 OpenAI Chat Completions 兼容协议及 Anthropic Messages，密钥只在后端使用。向量检索使用已准备的当前 Embedding 配置；不可用时提示并退回主题词检索，不自动准备索引。

每次先扩展最多 8 个检索词，融合词面与向量候选后，最多向模型发送 16 条材料摘录，摘录总计不超过 8,000 字符。输出 token 上限分别为 1,000 / 1,800；GPT 模型使用低推理预算。最终最多选 10 条，标题最多 16 字符。未解锁、不可读的日记不进入模型材料。

找材料不创建卷或修改绑定。保存前核对每条来源的当前内容凭据；漂移则拒绝保存，重复请求按请求 ID 幂等处理。“保存叙事线”创建空白 collecting 卷；明确点击“书写”会调用公开版 Writer 并保存首篇正文。已有正文的更新／重写仍先预览再确认保存；主题独立于短书名传给 Writer，保留配置姓名和原文图片读取规则。

修订扫描开始前，撤出 archived/superseded Event 和 archived Scene 的绑定，保留原始材料、已写正文、发布日期和历史。绑定修订会递增版本，但不单独制造新的修订提醒；已有提醒的处理状态保留。缺失或删除的材料仍交由现有审阅流程处理。旧 Arc key 缺失不会阻断这一流程。

## 修订箱材料与候选续攒

候选材料展开后分页显示类型、当前标题和日期，点击用只读小卡片读取全文；卡片可独立滚动、Esc关闭并恢复焦点。材料标题与全文都重新检查读取权限，删除、锁定材料不显示旧正文。每页50条，可继续加载；组标题显示实际材料数量。

自动 Scout 会参考最多24条待判断候选，优先选与本轮检索材料重合的候选；额外候选摘要输入最多16000字符。模型确认同一条持续叙事后返回已有 proposal_id，后台保留原候选编号、标题、创建时间和人工草稿，按类型与ID去重追加。一次只新增一条也可以。未指定已有候选的重叠分组不另建卡；同一组材料改标题不会重复创建。已忽略/已处理的候选不会自动重开，写入事务中重新核对材料状态和正式绑定，防止扫描期间的变更被旧结果覆盖。已有重复卡不会因此自动删除或合并。

新候选单次仍最多40条Event及40条Scene，默认检索为24条种子、每条最多12条邻近材料；累积对齐叙事卷编辑器的每类500条上限。到达上限会保留候选并明确提示，本次整组追加停止，不静默截断。此上限限制材料引用数，不代表这些正文能一次放入Writer模型；书写仍遵守原有输入预算和预览/保存边界。自动成卷候选目前仍只收Event与Scene；日记等材料卡用于兼容已有来源记录，不扩展自动扫描范围。
