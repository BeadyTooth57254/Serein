# 记忆保存与读取规则

Scene/Event ID、版本、绑定原文和对象生命周期各自保留。一个 active Scene 覆盖某 Event 全部有效原文快照时，Event 仅停止自动浮现；多个部分覆盖 Scene 不合并冒充完全覆盖。删除、锁定、替换后的正文不通过历史版本绕过读取约束。

主库提交与派生索引状态分开：写入成功但索引失败时仍报告 canonical success 和 pending，持久任务继续重试。过期向量不冒充当前正文。

自动混合选卡保留六个直接候选，开启“联想”后最多增加一个已确认关系相连的 Scene，共用一次 reranker、至多两卡、0.65 reranker 门槛、无通用向量门槛、冷却后不补位。路由类别动作和低置信度最终动作分开，两层 gate 保持有效。日期与来源时间在有记录时保留；原文证据在显式读取时返回，缺失时不编造。

候选、准入、阅读投影、渲染和实际注入仍是不同结果。卡片 score 是向量证据分；reranker 分在诊断中。低置信度或不相关候选不保证成为注入内容。没有新增“是否值得提起”的独立模型。

历史已有的 self_anchor metadata 不恢复独立“自我”分类，也不自动转成收藏或梦境身份锚点；从 Ombre 旧库迁移时，带旧自我锚点标记的正文直接丢弃。持续更新的窗影表达流动的“自我”。收藏是显式标记，不改变召回分数或冷却。

## 叙事卷保存

成卷候选可保存空白叙事线或明确点击“书写”生成并保存首篇正文；已有卷的更新/重写仍先预览再确认。只保存材料仅适用于正文为空的 collecting 卷。修订提示的“本次不影响”通过同一事务撤回新增 Arc 材料关联，保留原始记忆和已写正文；重新打开提示不会自动重新绑定。
